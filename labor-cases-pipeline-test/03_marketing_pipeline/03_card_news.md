# 카드뉴스 스토리보드 (P5 일반 시민 / 인스타·스레드용)

> 8장짜리 카드뉴스. 각 장 = 250자 이내. 한 장 = 한 명제.
> 디자이너에게 그대로 넘길 수 있는 spec.

## 카드 1 — 커버

```
[배경: 회의실 실루엣, 한 명만 컬러로]

당신은 회사 감사실에서
무슨 말을 할 수 있다고 생각하나요?

— 2024두64888이 던진 질문 —
```

## 카드 2 — 사건의 시작

```
[배경: 종이가 흩어진 책상]

학교법인이 운영하는 실버타운.
입소자 보증금 120억이 사모펀드에서 사라졌습니다.

이 사실을 알게 된 두 직원
A와 B의 이야기.
```

## 카드 3 — 비위행위

```
[배경: 노트북 화면, 잠금 해제 아이콘]

A는 회사 서버에 무단 접근해
사장과 임직원 이메일 22개를 열람했습니다.

이 행동의 동기를 두고
회사와 직원의 주장이 갈렸습니다.

(회사: 무단접근. 직원: 사장이 부탁한 일.)
```

## 카드 4 — 감사

```
[배경: 미팅룸 한 자리, 빈 의자]

2021년 3월 3일.
회사 감사실에서 A와 B가 조사를 받았습니다.

A: "제 변호사와 함께 받겠습니다."
감사반: "안 됩니다."

이 한 마디가 5년의 분쟁을 시작했습니다.
```

## 카드 5 — 1심·2심

```
[배경: 법원 외경 실루엣]

1심: "회사 규정에 변호사 조력 의무가 없습니다."
2심: "묵비권 고지가 있었으니 방어권은 보장됐습니다."

두 법원 모두 회사 손을 들어줬습니다.
```

## 카드 6 — 대법원의 질문

```
[배경: 책 더미 위 작은 등잔]

대법원은 다른 질문을 던졌습니다.

"사인(私人) 간 징계조사에서
근로자가 변호사와 동석할 권리가 있는가?"

이건 단순한 절차 문제가 아니라
헌법의 질문입니다.
```

## 카드 7 — 왜 중요한가

```
[배경: 무수한 회의실 윈도우]

이 질문에 대법원이 어떻게 답하든,
대한민국의 모든 사내 감사 절차가
새로 설계됩니다.

당신이 직원이든, 인사담당이든,
대표든 — 무관하지 않습니다.
```

## 카드 8 — CTA

```
[배경: 한 손이 다른 손을 잡는 일러스트]

회사 감사실에서 호출 받았을 때,
첫 5분에 무엇을 해야 하는가.

→ 전문가가 만든 "근로자 대응 매뉴얼"
   프로필 링크에서 무료 다운로드.

#노동법 #부당해고 #근로자권리 #2024두64888
```

## 운영 가이드

| 항목 | 설정 |
|---|---|
| 포맷 | 1080×1080 정사각, 인스타·스레드 동시 |
| 발행 시간 | 화·목 오전 9시 (직장인 출근 직후) |
| 캡션 | 카드 1, 6 텍스트 재활용 + 해시태그 8개 |
| 댓글 픽 | 카드 4 ("이 한 마디가 5년의 분쟁을 시작") 댓글 유도 |
| 후속 콘텐츠 | 1주 후: P3 후크 4 ("감사 받기 전, 단 5분만 읽어야 할 한 페이지") 롱폼 연결 |

## 주의 사항

- 카드 6에서 **대법원 결론을 단정하지 말 것**. "질문을 던졌습니다"까지만.
- 모든 텍스트에서 학교법인 C·회사 F·이사장 I/J·원고 A/B는 **익명** 유지.
- 카드 8 매뉴얼 다운로드 CTA는 **법률 자문 광고가 아닌 정보 제공** 형식으로 (변호사법 §23,
  §31 검토 필요).
