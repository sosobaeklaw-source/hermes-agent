## 5. 카피라이팅 가이드

| 항목 | 규칙 |
|---|---|
| 결과 단정 | 대법원 결론 자료 미공개 → "대법원이 정식 쟁점화"까지만. "대법원이 인정했다" 절대 금지. |
| 익명성 | P1~P5 모두에서 학교법인·회사·이사장·직원 실명/구체 추정 가능 정보 노출 금지 |
| 변호사법 | "100% 승소", "확실한 구제" 등 절대적 표현 금지. "정보 제공", "가이드", "체크리스트" 톤 유지 |
| 클레임 | "5년 분쟁"은 사실(2021. 4. 해고 → 대법원 진행 중)에 기반. 과장 아님. |
| 데이터 인용 | 자료 외 인용 시 출처 표기 의무 (학회·통계) |

## 7. 위험 관리 (Compliance)

- **변호사법 §23** (광고 제한): "변호사가 아닌 자"의 법률 자문 광고 금지. 본 카피는 **정보 제공·매뉴얼
  안내** 형식이며 개별 사건 자문 권유 아님.
- **표시광고법** §3 (부당광고): 결과 보장·통계 과장 금지. 본 카피 검토 시 결과 단정 표현 전수 검수.
- **개인정보보호법**: 리드 폼 수집 시 동의·이용목적 명시 (이메일 → 가이드 발송 + 7일 후속).
