# Atom Graph (Mermaid)

> 이 그래프가 곧 "법률문서 파이프라인의 base graph". 노드는 atom, 엣지는 `related` 메타데이터.
> Obsidian에서 graph view로 보면 사실(F)·법리(D)·판단(R)·결론(O) 클러스터가 명확히 분리됨.

```mermaid
flowchart TB
    subgraph PARTIES["당사자"]
        P1[P-001 학교법인 C]
        P2[P-002 회사 F 실버타운]
        P3[P-003 원고 A 전산담당]
        P4[P-004 원고 B 시설관리]
    end

    subgraph FACTS["사실관계"]
        F1[F-001 사모펀드 환매중단]
        F2[F-002 교육부 현장조사]
        F3[F-003 회사 종합감사]
        F4[F-004 A 서버 무단접근]
        F5[F-005 A 사장이메일 무단접근]
        F6[F-006 A 인사기록 임의삭제]
        F7[F-007 B 사주]
        F8[F-008 공익제보 항변]
        F9[F-009 변호사동석 요청]
        F10[F-010 A 진술포기]
        F11[F-011 B 자백취지진술]
        F12[F-012 형사 1심 유죄]
        F13[F-013 B 친인척관계]
    end

    subgraph PROC["절차"]
        PR1[PR-001 감사반 임의문답]
        PR2[PR-002 징계위원회]
        PR3[PR-003 징계해고 통보]
        PR4[PR-004 서울지노위]
        PR5[PR-005 중노위 재심]
        PR6[PR-006 1심]
        PR7[PR-007 2심]
        PR8[PR-008 대법원]
    end

    subgraph ISSUES["쟁점"]
        I1["I-001 변호사 동석권<br/>★핵심★"]
        I2[I-002 사실오인]
        I3[I-003 양정 일탈]
        I4[I-004 규정 합리성]
    end

    subgraph DOCT["법리"]
        D1[D-001 회사 징계 규정]
        D2[D-002 징계재량권 일탈남용]
        D3[D-003 해고 정당성 종합 판단]
        D4[D-004 비밀유지의무]
        D5["D-005 변호인조력권<br/>사인간효력 (쟁점)"]
    end

    subgraph REASON["판단"]
        R1[R-001 1심 절차하자 X]
        R2[R-002 1·2심 공익제보 부정]
        R3[R-003 1·2심 양정 적정]
        R4[R-004 2심 규정 적극정당화]
        R5["R-005 2심 시점특정<br/>★전환점★"]
        R6[R-006 2심 오기 정정]
        R7[R-007 2심 형사판결 편입]
        R8["R-008 대법원 쟁점형성<br/>★핵심★"]
        R9["R-009 심급간 분기점 분석<br/>★메타★"]
    end

    subgraph OUT["결론"]
        O1[O-001 1심 기각]
        O2[O-002 2심 기각]
        O3[O-003 대법원 미확정]
    end

    %% 사실 → 절차
    F1 --> F2 --> F3
    F3 --> F4 & F5 & F6
    F4 --> F7
    F3 --> PR1
    PR1 --> PR2 --> PR3 --> PR4 --> PR5 --> PR6 --> PR7 --> PR8

    %% 절차 → 결론
    PR6 --> O1
    PR7 --> O2
    PR8 --> O3

    %% 쟁점 → 법리
    I1 -.근거.-> D1 & D5
    I2 -.근거.-> D3
    I3 -.근거.-> D2 & D3 & D4
    I4 -.근거.-> D1

    %% 핵심 사실 → 쟁점
    F9 ==변호사동석요청==> I1
    F8 ==공익제보주장==> I2
    F4 & F5 & F6 & F7 ==비위행위==> I3
    F10 & F11 ==소명기회==> I1

    %% 판단 → 쟁점
    R1 -.적용.-> I1
    R2 -.적용.-> I2
    R3 -.적용.-> I3
    R4 -.적용.-> I4
    R5 -.재구성.-> I1
    R8 -.정식화.-> I1
    R9 -.메타분석.-> I1

    %% 판단 흐름 (핵심 발전선)
    R1 ==>|"2심 강화"| R4
    R1 ==>|"2심 시점특정"| R5
    R5 ==>|"대법원 받음"| R8
    R4 ==>|"대법원 검토 대상"| R8
    R8 ==>|"메타분석"| R9

    %% 스타일링
    classDef hot fill:#ffe4b5,stroke:#d2691e,stroke-width:3px
    class I1,R5,R8,R9,D5 hot
```

## 그래프 사용법

1. **시각 진입점**: 노란 박스(I-001, R-005, R-008, R-009, D-005)가 본 사건의 **법리적 전환점**.
2. **사실 → 쟁점 추적**: F-009(변호사동석 요청) → I-001(쟁점) → D-005(법리)가 가장 굵은 선.
3. **시간 흐름**: 좌측 PROC 칼럼이 시간축. PR-001 → PR-008.
4. **추상도 흐름**: 사실(F) → 절차(PR) → 쟁점(I) → 법리(D) → 판단(R) → 결론(O) 순으로 추상화.
