# 법리 발전 다이어그램 — 같은 사건이 권리 일반론으로 추상화되는 과정

> "LLM이 대법원처럼 사고한다"의 조작적 정의: **사실관계로부터 시작해 추상도 ↑↑↑까지 끌어올려
> 질문을 재형성할 수 있는 능력**. 이 문서가 그 사다리.

## 1. 추상화 사다리(Ladder of Abstraction)

```
                     ┌───────────────────────────────────────────────┐
       Level 5       │ 헌법 §12④ 변호인조력권의 사인 간 효력         │  ← 대법원이 묻는 질문
       (헌법원리)    │ "기본권의 대사인적 효력은 어디까지 인정되나"  │
                     └───────────────────────────────────────────────┘
                                       ▲
                     ┌───────────────────────────────────────────────┐
       Level 4       │ 근로계약 부수의무로서의 절차적 공정성         │
       (계약법리)    │ "사용자의 신의칙상 의무는 어디까지인가"       │
                     └───────────────────────────────────────────────┘
                                       ▲
                     ┌───────────────────────────────────────────────┐
       Level 3       │ 징계 절차 일반 법리                           │  ← 2심이 사고하는 레벨
       (절차법리)    │ "방어권 보장의 충분성 판단 요소는 무엇인가"   │
                     └───────────────────────────────────────────────┘
                                       ▲
                     ┌───────────────────────────────────────────────┐
       Level 2       │ 취업규칙·인사규정·정관                        │  ← 1심이 사고하는 레벨
       (규정해석)    │ "이 회사 규정에 어떤 의무가 명시되어 있나"    │
                     └───────────────────────────────────────────────┘
                                       ▲
                     ┌───────────────────────────────────────────────┐
       Level 1       │ 사실 자체                                     │
       (사실인정)    │ "그날 무슨 일이 있었나"                       │
                     └───────────────────────────────────────────────┘
```

## 2. 같은 사실, 다른 레벨의 질문

**원사실**: "2021. 3. 3. 감사반이 원고들에게 임의문답을 실시하면서 변호사 동석 요청을 거부했다."

| 레벨 | 그 레벨에서 던지는 질문 | 답 |
|---|---|---|
| L1 | 무슨 일이 있었나? | 변호사 동석 요청이 있었고 거부됨. |
| L2 | 회사 규정에 변호사 동석 보장 의무가 있나? | 없다. → 절차 하자 X (1심) |
| L3 | 그 절차 단계에서 방어권은 충분히 보장되었나? | 묵비권 고지 등이 있었다. → 절차 하자 X (2심) |
| L4 | 사용자에게 신의칙상 변호사 조력을 허용할 부수의무가 있나? | (대법원이 검토) |
| L5 | 변호인의 조력을 받을 권리(헌법 §12④)가 사인 간에도 효력을 미치나? | (대법원이 정식 쟁점화) |

**핵심 통찰**: 한 레벨에서 만족스러운 답을 얻어도 거기서 멈추지 않는 것이 상급심이 하급심을
넘어서는 방식. **LLM도 같은 동선을 따라가도록 훈련해야 함**.

## 3. 도그마(부정설) vs 진보(긍정설)의 구조적 대립

```
                 ┌──────────── 부정설 (1·2심) ────────────┐
                 │                                         │
   "변호인 조력권" ─┤  형사절차·공권력 한정                  │
                 │  사인 간 직접효 없음                    │
                 │  근거: 헌법 §12④ 문언 + 종래 판례       │
                 │                                         │
                 └─────────────────────────────────────────┘

                 ┌──────────── 긍정설 (대법원 검토방향?) ──┐
                 │                                         │
   "변호인 조력권" ─┤  적법절차 일반론으로 확장              │
                 │  사인 간 효력 인정 (수평효)             │
                 │  근거: ① 헌법 §10 일반적 인격권          │
                 │        ② 헌법 §12④ 확장적 해석          │
                 │        ③ 신의칙 (민법 §2)                │
                 │        ④ 근로계약 부수의무               │
                 │                                         │
                 └─────────────────────────────────────────┘
```

## 4. 1심·2심·대법원 사고 패턴 비교

### 1심의 사고 패턴

```
사실 → 회사 규정 검색 → 명시 의무 X → 의무 없음 → 절차 하자 X
                                          │
                                          └─ "막연히 주장 + 입증 부족" 보강
```

특징: **명시적 규정 의존**. 부정 추론(absence → no duty). 헌법적 권리는 시야 밖.

### 2심의 사고 패턴

```
사실 → 시점 정확히 특정 → 그 시점에서의 방어권 종합 평가
                          ├─ 묵비권 고지 O
                          ├─ 출석·진술 기회 O
                          └─ 규정 자체의 합리성 O
                          → 절차 하자 X (논거 강화)
```

특징: **단계적 사실 정리 + 다요소 종합 평가**. 1심을 강화하지만, 시점 특정이 결과적으로
대법원의 새 쟁점 형성을 가능하게 함.

### 대법원의 사고 패턴

```
사실(2심 그대로) → 질문 재구성: "이건 사실 회사 규정 문제가 아니라 권리 자체의 문제"
                                    │
                                    └─ 권리 일반론으로 추상화
                                       ├─ 근거: 헌법 §12④?
                                       ├─ 근거: 신의칙?
                                       ├─ 범위: 동석만? 진술대리?
                                       └─ 효과: 절차 하자 → 처분 위법?
```

특징: **추상도 점프**. 사실은 그대로 두고 **질문의 레벨을 통째로 올림**. 이것이
"대법원처럼 사고한다"의 본질.

## 5. LLM 훈련 시사점

LLM에게 부당해고 사건을 던지면 보통 **Level 2-3에서 멈춤**. 회사 규정 검색, 절차 단계 평가까지는
하지만 **Level 4-5의 권리 일반론으로 점프하는 경향은 약함**.

이를 보완하려면 SFT/DPO 단계에서:
1. **"이 사건을 Level N에서 답해보라"** 형식의 단계별 프롬프트 학습
2. **"이 답에서 한 레벨 더 추상화하면?"** 형식의 self-refine 학습
3. **"이 결론을 깨려면 어느 레벨에서 다른 질문을 해야 하는가?"** 형식의 adversarial 학습
